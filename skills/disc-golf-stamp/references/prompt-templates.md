# Disc Golf Stamp Prompt Templates

> All stamps are **single-color line art on solid magenta (#FF00FF) background**. No color, no gradients, no shading. All detail comes from line weight, crosshatching, stipple, and solid fills. The result should look like it could be cut as a foil stamp plate.

## Base Format (append to every prompt)

```
Rendered entirely in black ink — solid black lines, fills, and textures only. No gradients, no halftones, no grayscale shading, no color. All detail through line weight variation, crosshatching, stipple dots, or solid black fills. The artwork must read as a single-color stamp design. Circular composition designed for a disc golf disc stamp.
Isolated centered on a solid flat uniform magenta (#FF00FF) background with no gradient, no shadow, no lighting on the background.
```

## Double Stamp (Two Colors)

Generate **two separate images** — one for each foil color layer. Each layer follows the same line-art-on-magenta format.

**Layer 1 prompt:**
```
[DESCRIBE the elements that will be foil color #1]. Rendered entirely in black ink on magenta. [Same base format as above]. This is layer 1 of a two-color stamp — only include elements for the [PRIMARY COLOR] foil pass. Leave at least 1/16 inch of clear space around all elements for registration tolerance. [Same magenta background instruction].
```

**Layer 2 prompt:**
```
[DESCRIBE the elements that will be foil color #2, maintaining the same composition as layer 1]. Rendered entirely in black ink on magenta. [Same base format as above]. This is layer 2 of a two-color stamp — only include elements for the [SECONDARY COLOR] foil pass. Elements must not overlap with layer 1 and must maintain at least 1/16 inch gap. [Same magenta background instruction].
```
